# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some Oxlint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the Oxlint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and Oxlint's TypeScript related rules in your project.
# Student Profile

The **Student Profile** is a simple React-based web application designed to display student information in a clean and organized profile card. The application demonstrates the use of **React components and props** to pass and display details such as student name, roll number, course, and college. It is a beginner-friendly project for understanding the fundamentals of React and component-based development.

## Live Demo

You can view the Student Profile application using the following local development link:

**[Student Profile – Live Demo](http://localhost:5173/)**

## Features

- Displays student profile details
- Uses React components
- Demonstrates React props
- Simple and clean user interface
- Beginner-friendly project structure

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the application at:

**http://localhost:5173/**

## Project Purpose

This project helps beginners understand how **React components and props** are used to create reusable and dynamic user interfaces.
